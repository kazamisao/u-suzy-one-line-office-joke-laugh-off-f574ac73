# One-Line Office Joke Laugh-Off

The joke borrows the driest form in the office — the emergency-contact field — and fills it with the one person whose care is professionally transactional: the recruiter who placed the narrator in the job. When he collapses at his desk, she does come running, defibrillator in hand. She also brings three roles he would be perfect for, because a recruiter's rescue and a recruiter's pitch are the same visit.

The program is a single standard-library file. It holds the line, checks it against the 1–200 character window, and writes it to the output directory exactly the same way on every run.

## Run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
